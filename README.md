#DNA Sequence Analysis

A Python-based bioinformatics project for retrieving, analyzing, storing, and visualizing DNA sequences.

This project combines **Python, Biopython, SQLite, SQL, Pandas, and data visualization** to explore biological sequence properties and demonstrate a basic computational biology workflow.

---

##Project Overview

The project takes DNA sequences and performs several analyses, including:

- DNA nucleotide composition
- Sequence length analysis
- GC content calculation
- AT content calculation
- DNA melting temperature (Tm) calculation
- Sequence retrieval from NCBI using Biopython
- SQL-based storage and querying
- Data visualization

---

- **Pandas**
